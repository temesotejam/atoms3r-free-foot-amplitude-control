# 0.47.22: 姿勢STOPを前後だけに限定

ユーザー指定により、横倒しを姿勢STOPの対象から除外する。
0.47.21の「直立方向への投影が0以下」という全方向判定をやめ、
機械直立からの前後角が±90度に到達したときだけ姿勢STOPする。
左右揺動の角度が大きいこと自体では停止しない。

## 軸と判定

取り付けと既存座標定義に従い、MEKFのX軸まわりが前後、Y軸まわりが左右。
固定の機械直立ベクトルで取り付けの傾きを補正する。表示ゼロは使わない。
既存MEKFクォータニオンから重力方向を求め、機械座標の前後面へ投影する。
通常のZYX角で、この投影は `cos(左右角) * [sin(前後角), cos(前後角)]` になる。

左右角が90度を越えると両成分の符号が反転し、単純なatan2やEuler rollは
180度飛ぶ。この飛びを前後転倒と誤認しないよう、前のサンプルと連続する
投影方向を選ぶ。STARTごとに直立側へリセットし、前後角のcos成分が0以下に
なれば `fore_aft_tilt_90deg` で既存ESTOP経路へ入る。
新しい姿勢推定器や逆三角関数、ヒープ確保、待ち時間は追加しない。

ちょうど横向きの90度では前後面への重力投影が消えるため、その瞬間は前の
判定方向を保持し、横倒しを理由にSTOPしない。この方法は直立から開始し、
前後角を観測できるサンプル間の前後回転が90度未満であることを前提とする。
横向き90度のまま大きく前後回転する複合運動では、この投影だけから前後角を
一意に追跡できない。任意の3次元転倒を検出する判定ではない。

## 維持する動作

- IMU／MEKF無効・古い姿勢などの既存異常停止は維持する。
- 停止後に姿勢を戻しても自動再始動しない。
- 運転中のWi-Fi／HTTP停止、終了後の通信復帰、RWLOG・足CSVの回収は同じ。
- USB診断の明示的ON/OFF、制御計算、足校正、制御期限2.5 msは同じ。

## 検証

校正直立を実際のMEKF初期化へ渡して姿勢系列を作り、前後±90度の境界、
左右±360度の通過、前後±80度までと左右傾斜の組み合わせ、横倒し後の前後STOP、
yaw変更、クォータニオン符号反転、次測定のリセット、古い／無効な姿勢を試験する。
実機での停止角度と処理時間は未確認。
