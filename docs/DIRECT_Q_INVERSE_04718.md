現在の補正設定では、振幅モデルは `A_pred = A_free + g_side * Q` です。
直接逆算した非負Qを、従来の100 ms時の予測Qで上限処理した後、既存の方向別積分補正を加え、もう一度出力範囲へ制限します。途中の幅の丸めだけを除去し、積分器本体の更新式と飽和時の積分停止処理は保ちます。現在無効の応答補正についても、上下限で切り替わる3区間の一次式を扱える逆算です。非有限値、非正のゲイン、不正な時定数は出力判断を無効にします。

通電時間は次の式を使います。電流はmA、tとτは秒、QはmA·sです。

`Q(t) = abs(I_inf*t + (I0-I_inf)*tau*(1-exp(-t/tau)))`

逆向きの残留電流があると、符号付き積分は電流ゼロの時刻で増減方向を変えます。その前後を分け、`+Q_target` と `-Q_target` の両方を確認します。各単調区間を最大7回の二分で絞り、整数msの隣接候補と区間端を比較します。最終幅はQの絶対誤差が最小のもの、同点なら短い幅、Q=0なら無出力です。候補ごとに角度や位置エネルギーを計算しません。

今回の量子化基準はQ誤差です。旧版の途中の1 ms量子化と最終エネルギー誤差による選択からは意図的に変わっています。予測エネルギー、次ピーク、支持域外の診断は引き続き記録し、エネルギー関数の定義域検査も残します。ホストでの同じ入力の再計算は、変更後の実際の軌道や実機時間を再現するものではありません。

同じ5回のfloat32入力346件での比較結果は、272件が同じ幅、41件が−1 ms、33件が＋1 msでした。差の最大は1 msで、上下限の飽和フラグは全件一致しました。旧版のモデル計算はキャッシュ後7,583回、次版の電流積分評価は3,003回です。前者は電流積分に加えて振幅・エネルギーまで計算するため、これは同一処理の時間比ではありません。旧版の論理候補数15,224回を旧版の実計算回数と取り違えないでください。

検証は実際の制御関数の判断部分を取り出してコンパイルし、旧版固定コードが記録された幅と一致すること、新版が0〜100 msの101候補を全評価したQ誤差最小値と一致することを確認しました。別途20,000状態の全候補比較、逆向き残留電流の複数解、10,000状態の独立した振幅逆算、ゼロ・上下限・非有限入力を検証しています。ホストの浮動小数点検証はESP32-S3上の計算時間や実機運動の保証ではありません。
