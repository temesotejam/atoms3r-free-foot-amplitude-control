## 変更した計算

### MEKF の構造上不要な積を省く

6 状態の MEKF は姿勢誤差 3 成分とジャイロバイアス 3 成分を保持する。
旧コードは、ゼロや単位行列を含む変換を一般的な 6×6 行列積で計算していた。

- 予測の遷移行列は `Phi = [I-W*dt, -dt*I; 0, I]`。
  `Phi*P*Phi^T` の行列積部分を 432 積から 144 積へ整理した。
- 加速度の観測行列は `H = [skew(h), 0]`。
  バイアス側の既知のゼロ列の積を省いた。
- Joseph 更新の `A = I-KH` は `[A00, 0; A10, I]`。
  単位行列との積をコピー・加算に置き換え、交差共分散もすべて計算する。
- リセット変換は `G = [I-0.5*skew(dtheta), 0; 0, I]`。
  `G*P*G^T` の行列積部分を 432 積から 108 積へ整理した。

上記はソースから数えた積の回数であり、処理全体の実測速度比ではない。
非ゼロ項の加算順序、Joseph 形式、共分散 36 成分、対称化、ノイズ係数を保つ。
姿勢推定のモデルを低次元化したり、加速度更新を間引いたりしていない。
クォータニオン・3 軸角度・バイアスの推定と診断も継続する。

### 表示用データの文字列コピー

`captureRunState` の状態名とエラー文字列は、書式展開のない `%s` だった。
この 2 か所を `snprintf` から長さ制限付きの `strlcpy` に置き換えた。
バッファ容量、終端、切り詰め規則と公開周期は同じ。
文字列部分単独の旧所要時間は計測していないため、スナップショットの
約 303 us が全部なくなるとは予測しない。

IMU の取得順序と周期、10 ms の保護上限、ログ周期、MEKF の軸、足角度の校正、
V46al-R2 の制御式、3 ms 補償、300 mA / 100 ms 制限、カメラ観測を維持した。
0.47.8 の処理時間プロファイルと停止状態記録は引き続き利用する。

## 検証の範囲

旧ソースを namespace だけ変更した比較用実装として固定した。
元コミットとファイルの SHA-256 は比較用ファイル先頭に記録し、
比較実装はファームウェアにはリンクしない。

`test_mekf_sparse_equivalence.cpp` は次を検証する。

- 4 姿勢条件で合計 48,000 回の予測、24,000 回の加速度更新試行。
- 400 Hz / 200 Hz 相当、周期ゆらぎ、3 軸運動、バイアス、
  並進加速度の棄却、無効加速度、許容外 dt を含む。
- 別に、非対角成分を持つ正定値の共分散を使う 128 ケース。
- 各段階のクォータニオン、バイアス、3 軸角、診断値、全共分散を比較。
  ホストで 3,613,000 個のスカラー比較が一致した。
- ホスト上の参考所要時間も表示するが、合否の性能基準にはしない。

既存の回帰テスト、実機向けビルド、カメラタスクのリンク検査、公開バイナリの
検証も行う。**実機の処理時間が予算内に収まること、30 秒完走することは
この段階では未確認**。同じ測定区間のフィルタ時間、スナップショット時間、
最大受け渡し遅延と終了状態を次の RWLOG で比較する。
