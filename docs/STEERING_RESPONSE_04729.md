# 0.47.29：左右目標差に対する応答確認

0.47.28の3回（8° / 10° / 12°）では、独立ジャイロの旋回方向が実機と一致した。
ユーザーは角度を測っていないため、今回の旋回角度の精度は未検証。
制御完了期限2.5 msの超過は36,423回中0回、最大2.029 msだった。
ログは0.621 / 0.629 / 0.655 MBで、イベントの打切り・IMUの連番欠落はなかった。

一方、補正は全Runで±1°に達し、旋回が残った。
目標差の変更に実測ピーク差が追従しない区間があり、10° / 12°では
正側パルスが100 msに飽和した。左右差とyawの相関だけから、
目標差の操作に対する応答の向き・強さを確定することはできない。

## 8°用の既存補正との干渉を修正

前回ピーク残差モデルの適用判定へ、操舵後の片側目標ではなく、
ユーザーが選んだ平均目標角を渡す。
0.47.28では8°から0.01°を超えて目標がずれるとモデルが切れ、
Run 1の13.288秒から断続的に、15.044秒以降は継続して無効になっていた。

- 平均8°：10秒以降、従来のside別A_prev支持域内だけ適用する。
- 平均10° / 12°：従来どおり適用しない。
- 係数、±0.70°制限、支持域、時刻条件は変更しない。
- Q計算とピーク誤差には、実際の左右別目標を引き続き使用する。
- 片側±0.2°での残差モデルの精度は、今回の実機ログで改めて確認する。

## 同じ30秒内で小さな入力を与える

今回はyaw追従フィードバックを休止し、次の既知の目標差を与える。
平均目標をA0、目標オフセットをδとし、正側=A0+δ、負側=A0−δとする。
「正側・負側」は胴体の横揺れの符号であり、カメラの右足・左足ではない。

| モータ開始からの時刻 | 奇数Runの要求δ | 偶数Runの要求δ |
| --- | ---: | ---: |
| 0–10秒 | 0° | 0° |
| 10–18秒 | +0.2° | −0.2° |
| 18–26秒 | −0.2° | +0.2° |
| 26–30秒 | 0° | 0° |

時刻は負側ピーク候補の時刻で判定し、そのピーク確定後に変更する。
変更は有効な1往復につき最大0.08°、絶対値は0.2°まで。
表は要求値であり、実際のδは段階的に追従する。10/18/26秒ちょうどに
モータ指令が切り替わるわけではない。欠測・無効な周期では変更を保持する。
既に発行した指令の目標は、その応答ピークまで保持する。

正負の順序を連続Runで逆にすることで、時間経過による変化の影響を
比較しやすくする。機械の履歴や床条件まで同一になるわけではなく、
この確認だけで因果や安定性が確定するわけではない。
Run番号は本体の再起動で戻る。旧フィードバックのコードは残すが、
通常の開始処理は必ずResponseCheckを選び、Webにモード選択は追加しない。

## 操作

1. Web書込みページから0.47.29へ更新し、本体のWeb画面を再読み込みする。
2. まず平均目標10°で通常の30秒測定を行い、RWLOGと足CSVを保存する。
3. 電源を切らずに「ログを消去・次の測定へ」で、同じ10°をもう1回測定する。
4. 曲がった向きも記録する。角度の実測があれば推定精度も評価できる。

その後、8°で同様に2回測れば、既存補正の適用と応答を確認できる。
起動、直立判定、START/END各5秒、LED、HTTP休止・復帰、足CSVの操作は従来どおり。
10°での実際の左右目標は最大10.2° / 9.8°である。

## 記録と評価

RWLOG v53 / 112 bytesを維持する。高頻度の項目・センサ読取りは追加しない。
停止後に生成するsteeringメタデータへ、プロファイル、要求時刻、Runの順序、
フィードバック休止、前回ピーク補正の適用判定を記録する。
`steering_desired_difference_deg`はこの確認中は欠測値とする。
これは未使用の閉ループD目標であり、指令目標差は`2 * steering_delta_deg`である。
reasonは5=正のδ要求、6=負のδ要求、7=ゼロへ戻す要求。
反転中は要求の符号と現在のδの符号が一時的に異なる。

解析は同期用の5秒を除き、RUNNING区間に限定する。
各指令の`target_peak_deg`と対応するピーク、Q、パルス幅、飽和を対応付ける。
δが要求値に到達した区間と移行中を区別し、負側ピークから次の負側ピークまでの
同一位相のyaw差を用いる。EWMAの遅れを物理応答の遅れと混同しない。
目標差→実測ピーク差→yawの順に確認し、8°補正・支持域・飽和も同時に見る。

3 ms、300 mA、100 ms、30秒、IMU取得・制御完了の計測範囲、停止条件は維持する。
ホスト検証は指定入力・上限・リセット・目標保持・8°適用判定を検証する。
処理時間、操舵応答、直進改善の実機検証は0.47.29の次の測定で行う。
