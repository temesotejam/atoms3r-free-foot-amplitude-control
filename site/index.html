MEKF、3 ms ZEROクロス補償、ピーク/side判定、電流モデル、既存solver、Ki、300 mA・最大100 ms、非常停止、RWLOGダウンロードはV46ak基準のまま維持しています。

Camera共存 Phase 1

今回は足角度計算をまだ入れていません。 固定足完成版の制御・MEKF・RWLOG・Web UIをそのまま残し、GC0308を低負荷で動作させてもWi-Fi/Web UIが維持できるかだけを確認する版です。

Phase 1KはUSBシリアル専用デバッグ版です。Cameraの自動撮影は完全に停止しています。起動後はreceiver OFF / XCLK OFFの待機状態を維持し、USBシリアルから命令したときだけ状態を変えます。

115200 bpsのシリアルモニタで、s=状態表示、c=1枚だけ撮影、i=強制idle、p=センサ電源OFF、d=Camera完全deinit、h=ヘルプです。pとdは再起動まで戻せません。

USBログには2秒ごとのheartbeatと、Camera状態・AP接続台数・Internal/DMA/PSRAM残量・撮影時間を出します。まず何も送らずWebUIを確認し、その後cを1回ずつ送って挙動を比較します。

書き込み後はまずモータを動かさず、Wi-Fi AtomS3CAM_Q1_SHADOWへ接続し、最初に http://192.168.4.1/camera-health を開いてください。短い ok camera=... が出たら、続いて http://192.168.4.1/ の通常WebUIを確認します。

書き込み後の実験

  1. これまで通り、機体を安全な倒した状態にして電源を入れます。
  2. 起動から10秒経つと同期LEDが常時点灯します。これは「立ててよい」の合図です。
  3. 機体を立てて静止させます。実測した立位重力方向に約400 ms安定するとLEDが消灯します。
  4. Wi-Fi AtomS3CAM_Q1_SHADOW に接続し、http://192.168.4.1/ を開きます。
  5. targetは 8.0 deg固定です。
  6. 動画撮影を開始し、同期LEDが映るようにします。
  7. Start autonomous energy control を押します。
  8. START同期の最初のOFF区間でfresh Accelを約0.8秒平均し、Ry(180°)機体座標へ変換してMEKFを再初期化します。起動時に求めたGyro Biasも同じ座標変換で再適用します。
  9. その後のSTART/MID/END同期LEDパターンは従来通りです。30秒のモータ駆動測定後、RWLOGをダウンロードします。

測定中は大きな状態JSONを生成せず、小さな状態応答のみ1秒に1回確認します。ESTOPは41秒待たず表示に反映され、Emergency stopのPOSTも使用できます。
